# CONTENT MAPPING — 8 STAGES PER LEARNING MODULE

The content catalog contains 12 starter lessons per learning module (3 broad groups × 4 source stages). The game design catalog provides eight learning-stage maps per module. For this prototype only, the 12 lessons are distributed over eight visible stages using the following mapping:

- Stage 1: lessons 1–2
- Stage 2: lesson 3
- Stage 3: lessons 4–5
- Stage 4: lesson 6
- Stage 5: lessons 7–8
- Stage 6: lesson 9
- Stage 7: lessons 10–11
- Stage 8: lesson 12

This is a presentation mapping to show a longer learning journey with game checkpoints. It does not create new lesson content. The stage names, stage lesson themes, interstitial game IDs and checkpoint descriptions are read from `minigame-catalog.json` → `stage_map`.

The app's six top-level modules are:
- M01 Đệm hát
- M02 Luyện ngón
- M03 Fingerstyle
- M04 Nhạc lý
- M05 Cảm âm
- M06 Công cụ (utility hub; not a compulsory course)

The game catalog contains GM01–GM18. All game IDs are available from the stage pages. Their exact rules are described in `data/minigame-catalog.json`; implementation detail and prototype limitations are summarized in `FEATURE_MATRIX.md`.
