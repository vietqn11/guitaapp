# ASSET NOTES

The 15 WebP files in this prototype were included from the previously prepared Guitar Master visual concept asset pack. They are local, bundled prototype illustrations and do not load from external URLs.

These images are decorative visual assets for UI mockups. They are not verified teaching diagrams, exact chord fingering references, or technical fretboard charts. All chord diagrams in this prototype are rendered from code-based chord data; verify them against an authoritative guitar fingering source before educational release.

Do not describe these 15 files as downloaded Pexels/Unsplash photographs. The earlier Pexels download kit was a source list + downloader and did not contain downloaded stock photos. This prototype uses the available local concept pack only.

If replacing with stock photographs later, obtain each original file, retain creator/source/license metadata, and bundle the approved files locally so the APK can run offline. Do not use runtime remote image URLs.
